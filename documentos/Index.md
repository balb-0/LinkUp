Esta documentação está organizada em diferentes arquivos conforme apresentado abaixo.

### Gestão do Projeto

- **GestaoProjeto.md**: Documento que registra a evolução do projeto LinkUp, desenvolvido pelo grupo ao longo das sprints. Inclui análises detalhadas de cada sprint, com identificação de pontos fortes e fracos, ações de melhoria, reflexões sobre o desempenho da equipe e análise de riscos. Ao final, traz uma seção de análise *Post Mortem*, destacando os principais sucessos do projeto, desafios enfrentados, oportunidades de melhoria e lições aprendidas. Este documento serve como base para aprimoramento contínuo do processo de trabalho em equipe e entrega de valor.

### Processo de Desenvolvimento de Software

- **GestaoConfiguracao.md**: Documento que define as diretrizes para controle de versão e colaboração no desenvolvimento do projeto LinkUp. Aborda o uso do modelo GitFlow para organização de branches, estabelece convenções para commits seguindo o padrão Conventional Commits, e detalha políticas de push e pull request com foco em revisão por pares e integração contínua. Seu objetivo é garantir consistência, rastreabilidade e qualidade no código ao longo de todas as sprints.

- **GuiaPadroesDesenvolvimento.md**: Documento que estabelece práticas e padrões de desenvolvimento para o projeto LinkUp, promovendo consistência, legibilidade e escalabilidade do código. Define convenções de nomenclatura, formatação, estrutura de diretórios e arquitetura baseada em três camadas (Frontend, Backend e Persistência). Também orienta quanto ao uso de comentários, revisão de código, testes automatizados (unitários, integração e E2E), ferramentas como ESLint, Swagger e Cypress, além das tecnologias empregadas, como Angular no frontend e Node.js no backend.

### Desenvolvimento do Produto

- **Projeto.md**: Documento principal da documentação técnica do projeto LinkUp. Reúne todas as fases do desenvolvimento, desde o entendimento do problema, análise do negócio, definição de requisitos e modelagem de dados, até o projeto visual, solução técnica, testes e implantação. Serve como guia completo para compreensão da solução desenvolvida, incluindo os documentos de design, arquitetura de software, estratégias de testes, planejamento técnico e justificativas de decisão. É a referência central para qualquer pessoa que deseje entender o funcionamento, o propósito e os detalhes técnicos do projeto.

- **Manual-Instalacao.md**: Documento que orienta sobre como montar, configurar e utilizar o protótipo desenvolvido no projeto LinkUp. Inclui instruções para instalação de dependências, preparação do ambiente, execução do sistema e conexão com o banco de dados. Serve como guia técnico para desenvolvedores e usuários que desejam rodar o projeto localmente ou implantá-lo em produção.
